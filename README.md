# Finals-WebProgramming

Project Proposal: Personal Portfolio Website

1. Project Title
My Personal Portfolio Website

2. Project Overview
This project aims to create a personal portfolio website that introduces me, presents my skills, and showcases the projects and activities I have completed. The website will serve as a digital space where visitors can learn more about me and explore my work.

3. Project Objectives
- Create a website that introduces me and my background.
- Showcase my skills, experiences, and completed projects.
- Develop a responsive and user-friendly website.
- Apply HTML5 to a practical project.
- Provide contact information so visitors can reach me.

4. Proposed Website Pages

Home Page
- Short introduction and welcome message.
- Profile picture or personal image.
- Navigation links to other pages.

About Page
- Personal introduction.
- Educational background.
- Skills and interests.

Projects Page
- Display selected projects and activities.
- Include images, descriptions, and project details.

Contact Page
- Contact information.
- Social media links.
- Simple contact form.

5. Technologies to Be Used
- HTML5 – Website structure and content.

A complete, responsive, and multi-page personal portfolio website that works on mobile phones, tablets, and desktop computers.
